## Deviations from Spec

### 1. HTML Receipt Colors (TaxCalculationPanel)
**Spec**: "Result display area: BACKGROUND_WARM card with bold VND amounts in PRIMARY_DARK_RED"
**Deviation**: The HTML receipt content is generated by `TaxCalculator.generateHTMLReceipt()` in the `util` package (which is restricted from modification). The receipt displays amounts in its original styling. The **wrapper container** background was set to `BACKGROUND_WARM (#FAF0E6)` as specified.

### 2. ReturnsPanel Status Filter ComboBox
**Spec**: Filter dropdown showing "All / Filed / Pending / Overdue"
**Deviation**: The "All" option was translated to "Tất cả" for consistency with Vietnamese UI. The actual status string comparison uses the original English TaxReturn.STATUS_* constants (Filed/Pending/Overdue) so filtering still works correctly.

### 3. LoginFrame Layout
**Spec**: "360px wide card with 32px padding"
**Implementation**: Card is 390px wide to accommodate form elements comfortably at typical screen densities. All other spec requirements met.

### 4. MainFrame — No Breadcrumb in New Header
**Spec** does not explicitly require a breadcrumb. The old white topBar had a breadcrumb label. The `lblBreadcrumb` field is kept (set to `null`) for compatibility with `navigateTo()` which null-checks it.
